環境をセットアップします

設定をまとめて終えてから、ダウンロード / セットアップを実行します。

  1. 1バックエンドのインストール
  2. 2モデルと設定を選ぶ
  3. 3ダウンロード / セットアップ → 調整 任意

インストール / ダウンロードが済みなら プロファイル作成と調整だけ もできます。

セットアップ — プロファイル

プロファイルを作って調整します

起動プロファイルの作成と、この PC 向けの調整だけを行います。

  1. 1バックエンドとダウンロード済みのモデルを選ぶ
  2. 2稼働設定
  3. 3接続設定
  4. 4調整 任意

バックエンドのインストール / モデルのダウンロードが必要なときは 通常のセットアップ へ。
